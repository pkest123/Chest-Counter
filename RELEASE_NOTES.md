# v0.1.0 — notification accuracy update

Windows preview release of Chest Counter Classic.

Includes learned notification focus, buffered capture for brief popups, improved
OCR wording and XP matching, faster rearming, live CPU/RAM usage, continuous
selected-display capture and separate counter-window placement on monitor 2.

Extract the entire Windows ZIP and run ChestCounter.exe inside the extracted
folder. Keep _internal beside it. Existing counts and settings are retained.

This is a notification-based prototype. It does not guarantee every chest or
reliably count broken chests without a readable notification. See README for
known limitations and validation scope.

The release contains application files only, with no user recordings,
screenshots, session counts, local settings or credentials.
